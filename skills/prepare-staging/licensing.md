# Licensing

Every real APP publication needs `publication-staging/LICENSE`.

Ask the author which terms they want. Do not infer licensing. For standard licenses, fetch canonical text into a temporary file, fill placeholders, show it to the author, and move it into `publication-staging/LICENSE` only after explicit confirmation.

Common options to offer as examples:

- MIT
- Apache-2.0
- BSD-3-Clause
- CC-BY-4.0
- custom/multi-component terms

If paper, code, data, and supplementary materials have different terms, the root `LICENSE` must say so clearly. For custom or multi-component terms, ask the author to provide/approve the full text.

In dev-sandbox mode, a deferred license is allowed only as an explicit release-outcome blocker. In real publication mode, do not proceed without a license.
