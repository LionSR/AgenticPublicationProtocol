# Phase 6 — Final Outcome

Determine the mode before doing anything irreversible. Phase 5 review/freeze must be complete first; see [`review.md`](review.md).

- For real publication mode, follow [`release-real.md`](release-real.md).
- For developer sandbox mode, follow [`release-sandbox.md`](release-sandbox.md).

Do not mix the two outcomes. Real publication creates a public tagged release and APP manifest. Developer sandbox mode records only an implementation-test result and must not create APP compliance records.
